# 🥗 Рацион на неделю

**Меню на 7 дней под семью, бюджет и вкус** — с калориями, рецептами и списком покупок.

Telegram Mini App / веб-приложение: короткий опрос → свайп блюд → готовое меню и закупки.

---

## Возможности

| | |
|---|---|
| 🍽️ | **245 блюд** с рецептами и фото (русская, грузинская, азиатская, европейская кухни) |
| 👪 | Расчёт **КБЖУ на всю семью** с учётом порций |
| 💰 | Бюджет и **живые цены** (Магнит / кэш `prices_live.json`) |
| 👈 | **Свайпер** блюд с адаптацией под вкус (кухня, белок, теги) |
| 🍳 | Режимы готовки: обычный день, **batch**, разогрев, быстрые блюда |
| 🛒 | **Список покупок** по отделам, чекбоксы, экспорт |
| 💾 | Сохранение меню в `localStorage` — при повторном входе открывается сразу |
| 🌙 | Светлая / тёмная тема, адаптация под iOS и Telegram |

## Как это работает

```text
Опрос  →  Свайп блюд  →  Меню на 7 дней  →  Список покупок
  • семья          • нравится / нет     • КБЖУ по дням      • отделы
  • бюджет         • вкусовой профиль  • рецепты            • цены
  • аллергены      • адаптация колоды   • замена блюд        • экспорт
```

1. **Опрос** — состав семьи, бюджет, кухня, ограничения и нелюбимое.
2. **Свайп** — вправо / влево / «очень нравится»; колода подстраивается под ваши ответы.
3. **Меню** — 7 дней, макросы, рецепты, замена блюд.
4. **Покупки** — список по отделам с ориентиром цен и экспортом в `.txt`.

## Быстрый старт

Нужен локальный сервер (для `fetch` цен и картинок):

```bash
git clone https://github.com/DenchikBoss/racion-na-nedelyu.git
cd racion-na-nedelyu
python3 -m http.server 8080
```

Откройте [http://localhost:8080](http://localhost:8080).

Обновление цен вручную:

```bash
python3 parse_prices.py --magnit
```

---

## Цены

- Базовые цены зашиты в `main.js` (`BASE_PRICES` + алиасы ингредиентов).
- Живой слой — `prices_live.json`, который пишет **GitHub Actions**  
  (`.github/workflows/update-prices.yml`, cron `05/13/21 UTC`).
- В браузере цены подтягиваются из JSON с кэшем ~12 часов.

## Telegram Mini App

1. Задеплойте сайт на **HTTPS** (Netlify, Cloudflare Pages и т.п.).
2. В [@BotFather](https://t.me/BotFather) укажите URL как Menu Button / Web App.
3. На `/start` бот может отправить кнопку `web_app` с этим URL.

Приложение уже поддерживает `Telegram.WebApp` (theme, MainButton, haptic, viewport).

## Деплой

Удобный вариант — **Netlify**:

1. *New site from Git* → этот репозиторий.
2. Publish directory: корень репо (где `index.html`).
3. После деплоя подставьте URL в BotFather.

## Стек

- Чистый **HTML / CSS / JS** (без фреймворка на клиенте)
- **Python 3** — парсер цен
- **GitHub Actions** — обновление `prices_live.json`
- Хранение сессии: `localStorage` (`ration_v2`)

## Отказ от ответственности

Сервис **не заменяет** консультацию врача или диетолога.  
При заболеваниях и специальных диетах обратитесь к специалисту.  
Цены — ориентировочные и могут отличаться от витрины магазина.
