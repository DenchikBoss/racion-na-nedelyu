# MCP ВкусВилла: проверка (этап 1 ТЗ)

Проверено 2026-11-04 запросами с компьютера разработчика, без авторизации во ВкусВилле. Рабочая ссылка на корзину из 3 позиций получена, корзина открывается на сайте.

## Подключение

| Что | Значение |
|---|---|
| Адрес | `https://mcp.vkusvill.ru/mcp` |
| Протокол | Streamable HTTP, JSON-RPC 2.0, версия протокола `2025-03-26` |
| Заголовки | `Content-Type: application/json`, `Accept: application/json, text/event-stream`, обычный браузерный `User-Agent` |
| Сессия | заголовок `Mcp-Session-Id` сервер не выдал: вызовы работают без сессии после `initialize` |
| Ответ | `Content-Type: application/json` (не поток событий) |
| Лимит | 60 запросов в минуту: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset` (секунды до сброса) |
| Сервер | `VV MCP Server 0.0.1` |

Персональные инструменты (история заказов, личные скидки, наличие) требуют OAuth 2.0 + PKCE через `https://oauth.vkusvill.ru/`. Для корзины это не нужно.

## Инструменты для корзины

**`vkusvill_products_search`** — поиск товаров.

| Параметр | Значение |
|---|---|
| `q` | строка 1–255 символов, пустой запрос не принимается |
| `limit` | 1–10 на страницу, `page` — номер страницы |
| `sort` | `popularity` (по умолчанию), `rating`, `price_asc`, `price_desc`, `new` |
| `vvonly` | по умолчанию `1` — только товары бренда ВкусВилл |
| `mode` | `short` (по умолчанию), `full`, `custom` + `fields`: `id, name, slug, description, price, unit, weight, rating, url, images, category, properties` |

Ответ лежит в `result.content[0].text` как JSON-строка:

```json
{"ok": true, "data": {
  "meta": {"q": "молоко", "limit": 5, "total": 557, "page": 1, "pages": 112, "has_more": true, "personalized": false},
  "items": [{"id": 173, "name": "Молоко 3,2%, 1&nbsp;л",
             "price": {"current": 93, "currency": "RUB", "old": null},
             "unit": "шт", "weight": {"value": 1, "unit": "кг"},
             "url": "https://vkusvill.ru/goods/moloko-3-173/"}],
  "facets": {"categories": [{"category_id": 101, "category_name": "Молоко, сливки"}]}}}
```

**`vkusvill_cart_link_create`** — ссылка на корзину. Вход: `{"products": [{"id": 173, "q": 1}]}`, от 1 до 100 позиций, `q` от 0.01 до 40. Ответ: `{"ok": true, "data": {"link": "https://vkusvill.ru/mobile?basket&share=90224"}}`.

## Что выяснено по открытым вопросам ТЗ

| Вопрос | Ответ |
|---|---|
| Можно ли звать MCP из браузера (CORS)? | Нет. Предварительный запрос `OPTIONS` получает 401 без заголовков `Access-Control-*`. Серверная функция обязательна |
| Работает ли каталог без авторизации? | Да, `personalized: false`, цены есть, наличия нет |
| `id` или `xml_id`? | `id`, целое число из поиска |
| Что такое `q`? | Для товара с `unit: "шт"` — число штук (упаковок). Для `unit: "кг"` — килограммы: `q = 0.5` для бананов дал в корзине 0,5 кг |
| Сколько позиций на ссылку? | По схеме до 100. ТЗ предполагало 20–30; проверено на 1 и 3 позициях, большие списки стоит проверить отдельно |
| Сколько живёт ссылка? | Не проверено: нужна повторная проверка через сутки |

## Что учесть в словаре и функции

- В названиях встречаются HTML-сущности (`&nbsp;`): их нужно раскодировать перед показом.
- Вес упаковки есть только у штучных товаров (`weight.value` в кг). У весовых (`unit: "кг"`) поля `weight` нет, цена указана за килограмм.
- У яиц `weight` — масса упаковки, число яиц надо брать из названия («20 шт») или считать 10 по умолчанию.
- По умолчанию поиск ищет только бренд ВкусВилл (`vvonly=1`); для редких продуктов может понадобиться `vvonly=0`.
- Первая позиция по популярности не всегда та, что нужна (по запросу «гречка» есть «Ассорти каш»), поэтому словарь с `include`/`exclude` из ТЗ нужен.
- Ссылка ведёт на главную страницу с окном «С вами поделились товарами» и кнопкой «Проверить наличие товаров».
